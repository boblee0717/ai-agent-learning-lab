# Glossary

- Agent: a system that can decide actions while pursuing a goal.
- Brain: the decision maker. In real systems this is often an LLM.
- Tool: a callable capability outside the brain.
- Observation: the output returned by a tool.
- Trace: the record of decisions, tool calls, observations, and final answer.
- Memory: information carried across steps or conversations.
- Guardrail: a rule or check that keeps the agent inside intended behavior.
